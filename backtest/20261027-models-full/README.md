# 20261027-models-full — 阶段二全历史验证数据（种子 20261027）

本目录是 [20261027-models 双交易模型实验](../20261027-models/README.md) 阶段二（全历史分层抽样 200 起点 × 持有250交易日，固定每笔1万元口径）的原始输出，抽样种子 **20261027**。

- `samples.csv`：每个样本 × 每策略的 start/end/收益率/年化/T统计/区交易次数明细（含与阶段一选样窗口是否重叠标记）
- `report.json`：汇总表、选样窗口重叠分组（无偏检验）、逐样本配对优势（vs 基线）
