# 515180 纪律性操作回测实验总览

对中证红利ETF（515180）趋势通道交易系统的系列回测实验。标的无份额拆分、每年分红除息后价格回落，价格中枢长期围绕分红水平震荡，前复权序列忠实反映这一结构。

**数据口径**：20261022 起统一改用 **iFinD 前复权日线**（2019-12-20 上市 ~ 今，存 `_data/515180_daily_all.csv`）；此前实验受腾讯接口 640 条日K上限所限仅覆盖近两年，已在对应文档标注。**交易规则、费用（佣金万二最低5元）、信号机制（t 日前已完成周K拟合，无未来函数）各文档内详述**；操作单位经历了"固定股数 → 每笔固定1万元"的口径演进（见 20261022-stability-full caveat 与 20261027-models）。

## 当前推荐（20261027 起）

- **看板默认模型 = 优化版 B092**：通道 23%/77%（极端 2%/98%）、T = 近60日振幅 Q0.33×0.58（限 0.4%~1.5%）、区触发 ×0.63、T 单过夜（目标 +T×1.4 / 止损 −T×0.5 / 最长 5 日）、每笔固定 1 万元 + 5w 循环额度
- 实验纪律：**任何"最近一年表现好"的方案必须过全历史分层抽样关**（20261020-stability 与 20261027-models 两次教训）
