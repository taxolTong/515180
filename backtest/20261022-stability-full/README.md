# 20261022-stability-full — Top5 方案全历史稳定性（iFinD 数据源，分层抽样×1年×200样本）

## 目的

20261020-stability 受腾讯行情接口 640 条日K上限所限，实际只覆盖 2024-10~2026-10 两年（230 个起点全部落在同一行情段）。本实验改用 iFinD 全历史数据，把建仓起点分散到 2019 年上市以来各年份，重验 Top5 方案的稳定性结论是否成立。

## 数据源变更

- **iFinD 前复权日线**（2026-10-22 拉取，2019-12-20 上市 ~ 2026-10-21 共 1654 条，存 `../_data/515180_daily_all.csv`，3 段各≤3年拼接）
- 周K由日K按自然周聚合（周一首开盘价/周最高/周最低/周末收盘价），与腾讯 qfqweek 口径一致（2024-09 以来两家价格逐日核对完全一致；更早时段腾讯历史 qfq 复权因子偏小、低估历史分红，iFinD 为完整复权）

## 方法

- 命令：`node scripts/stability-full.mjs`（第 1 参数输出目录，第 2 参数样本数默认 200）
- 交易规则/信号/费用/Top5 方案与 20261020-stability 逐行一致；建模起点改为上市日 2019-12-20（权重模型随时间扩张）
- 全部 1370 个有效建仓日（2020-02-17~2025-10-09）按**建仓年份分层抽样** 200 个（2020:32/2021:36/2022:35/2023:35/2024:35/2025:27，种子 20261022）
- **复现校验**（先跑）：仅取 2024-09-01 起数据、同种子 20261020 抽 100 起点，结果与原实验高度一致（固定1万股均值 22.01 vs 21.94、中位 26.58 vs 25.60、P(亏损) 均 0%），确认换源后结论可复现

## 结论（对照原实验修正）

1. **方案排序 robust，绝对稳定性数字不 robust**：全历史下"单笔规模越大越好"的排序不变（1万元≈1万股 > 5000股≈5000元 >> pct50% 垫底），但原实验"固定1万股 0 亏损、最差 +2.97%"是两年窗口的产物——分散到全历史后它同样有 ~2.5% 概率亏损、最差 -9.80%（亏损样本均为阶段高位建仓后随板块回调的年份）
2. **固定1万元与固定1万股并列最优**（均值/标准差均 1.31）：全历史中 1万元法均值与最差还略优（早年低价位时 1万股/笔超额度被物理限缩，1万元法参与度更平滑）；两者差距在统计误差内
3. pct 仓位50% 全历史均值反而不低（26%），因几何加仓在 2020-2021 单边牛市中收益爆炸，但 P(亏损) 9.5%、中位数垫底——"看天吃饭"特征不变，**继续排除**
4. 做T 的 alpha 在全历史依然显著：Top 方案均值 32~34% vs 纯持有 4.88%，P(>20%) 57~60%
5. **数据口径 caveat**：前复权将历史价按累计分红因子下压（2020 年约 25%、2022 年中约 4.4%、2024 年中以来≈0），固定金额方案的买入股数 = 金额÷复权价，早年样本股数被**虚高**；amount_1万 的微弱优势主要来自 2020~2021 样本段，挤掉水分后与固定1万股实为并列甚至略逊——**维持原观点：固定股数/笔 + 5w 循环额度**（20261027-models 实验按用户要求已统一改为每笔固定1万元口径，详见 [../20261027-models/README.md](../20261027-models/README.md)）
