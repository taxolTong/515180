# 20261028-signal-close — 多过夜T + 昨收触发 + 0轴日内平回

复现：node scripts/model-signal-close.mjs 1000 20261028,20261029

每个种子不放回随机抽 1000 个起点，2 种子 × 1000 起点 × 3 策略 = 6000 次模拟；同一起点三策略配对比较。起点池 2020-01 起（模型需 60 日振幅窗口预热）。

> 注：本实验曾有前两版（20261027、20261028 早场），因过程缺陷且年化按底仓市值计严重虚高，已删除；本目录为唯一有效版本。

## 收益计算口径（真实投资）

- 真实投资金额 = 初始 1 万股 × 起点开盘价 + 5 万循环额度。
- 期末总资产 = 期末现金 + 期末持仓市值 + 5 万循环额度（现金下限 −5 万，加回后为实际权益）。
- 配对比较基于同一批起点，盈亏结论不受影响，仅年化数值更真实。

## 规则

- 初始现金 0；1 万股底仓 + 5 万元可循环额度；每笔固定 1 万元。
- **触发基准 = 昨收**：当日 high ≥ 昨收×(1+T) 触发卖出、low ≤ 昨收×(1−T) 触发买入，成交价 = 触发价（昨收±T）。
- **日内平回 = 回到 0 轴**：今收 ≥ 昨收则当日买入腿按今收平回，今收 ≤ 昨收则当日卖出腿按今收平回。日线数据下精确可判定。
- **多过夜腿并存**：每单独立计算自己的 5 天期限与止盈止损，最多 5 笔（5 万 ÷ 1 万）。单边下跌可连续 5 天用完 5 次加仓。
- **第 5 日强平抵消**：某腿满 5 日需尾盘强平，若当日有同向新触发，则抵消——不强平也不开新仓，继续持有；无同向触发才按收盘强平。
- signal 平回：反向触发价平掉全部反向旧仓（无相对买入价的止盈止损）。
- B092：每腿按自身买入价 +1.4T 止盈 / −0.5T 止损。
- control：绝不过夜、尾盘必平。
- 允许卖穿底仓但禁止负库存；同向卖出需净库存足够一笔 1 万元；区加减仓沿用旧实验。

## 结论

1. **维持 B092**：B092 胜 S-signal 的经验 p = 0.906，真实口径下超额年化 +2.28pp；对 control 也稳定胜出（p = 0.977，+1.90pp）。
2. **信号平回是负贡献**：S-signal 连 control 都打不过（超额 −0.38pp，胜率 0.432）。亏损腿要等反向信号才离场，第五日强平+抵消续持让亏损拖更久；单笔尾部（最差 −697 元、P10 −192 元）显著差于 B092（−320 元 / −40 元）。
3. **过夜 T 的价值来自价格目标退出机制**：B092 对 control 的 +1.90pp 才是过夜 T 的真实增量收益；0 轴平回规则本身高频可用（年均 11 笔左右），问题不在日内判定。
4. 真实投资口径下绝对收益预期约年化 11%（B092），此前按底仓计的年化 66% 是杠杆口径虚高，不应用于预期管理。
