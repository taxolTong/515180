# 20261027-models — 双交易模型实验：宽通道·高门槛（模型A）vs 参数寻优（模型B）

## 背景诉求（实盘反馈）

1. 做T失败率高（卖出后继续走高只能更高价买回、买入后继续走低只能低价再卖出）——期望抬高做T阈值：频率降低、触发时振幅更大、反转概率更高
2. 高/低估区阈值太窄，一年碰不到几次加减仓信号——期望放宽通道：更早加仓也更早减仓，放大仓位变化收益

要求：设计两个交易模型，先用最近一年大体测试，取最好的 3~5 个 case 放到更长历史（任意建仓周期）验证年化是否明显提高；统一控制变量：1万股底仓 + 5万活动资金（可循环、不可超额）。

## 控制变量（全部配置统一）

1万股底仓 + 1万现金 + 5万循环额度（现金下限 -5w，不可超额）、佣金万二最低5元、**每笔操作固定 1 万元（股数=1万÷成交价按100股取整，屏蔽前复权对固定股数操作价格的失真）**、信号用 t 日前已完成周K拟合（近期加权，半衰期26周）、数据源 iFinD 前复权日线（2019-12-20 上市起）。

## 引擎

`scripts/model-lib.mjs`：参数化通道分位数 zoneP/extremeP、T 系数 tK 与上下限、振幅窗口 ampWindow×分位 ampQ、区交易冷却 zoneCooldown、T 出场模式 sameDay/hold（hold 允许 T 单过夜：目标价=入场×(1±T×tgt)、止损=×(1∓T×stop)、最长 holdMaxDays 天后强制收盘了结；止盈止损同日都触及时按止损先成交，保守）。

## 两个模型

- **模型A「宽通道·高门槛」**：手工配置 5 组（通道 15/85~20/80、T×0.60~0.75、阈值下限 0.6%~0.8%、冷却 3~10 天、过夜持有）
- **模型B「参数寻优」**：13 维参数空间（zoneP 0.05~0.25、extremeP、tK 0.45~0.95、ampWindow/ampQ、tMin/tMax、zoneRatio、冷却、tExit、holdTargetK/holdStopK/holdMaxDays）固定种子随机搜索 400 组

## 结论

1. **B092、B223 跨操作单位口径稳健，是唯一通过全历史验证的方案族**：在"固定1万股"（第一轮，配对胜率 65%~70%）与"固定1万元"（本轮重选后对照，配对胜率 62.5%/55%~57%）两种口径下均稳定优于基线——不是选样运气，是真实结构优势；两配置同族（zoneP≈0.22、extremeP 0.02~0.08、tK≈0.58、zR≈0.62、tExit=hold、无冷却），任意建仓周期平均年化高 3~11pp，P(亏损) 与基线相当或更低
2. **换口径后重新选出的 Top5 几乎全部失效**（B274/B106 大幅跑输，B335/B072/B076 与基线持平）——单窗口+换口径重选的 top 依然不可信，验证了"必须过全历史关"的实验纪律；**模型A手工配置在两种口径下均未通过验证**
3. **两个诉求的回应**：①加减仓信号从基线年均约 9 次（买5.9/卖3.3）增至 B092 的约 19 次（买10.2/卖9.0），更早加仓也更早减仓——诉求达成，且这是新方案全部超额收益来源；②"抬高T阈值降低失败率"**未被证实**：胜率未随阈值抬升改善（全历史平均T胜率 38%~52%，做T本身是净亏损源——年均 T 净收益各配置均为负），真正消除失败场景的是 **T 单过夜持有机制**（把基线年均约 103 次"尾盘不利平回"降到 ≤1 次），止盈/止损/限期了结替代了尾盘强制平回
4. **推荐落地参数（B092，每笔 1 万元）**：低估/高估线 = 残差 23%/77% 分位，极端线 2%/98%；T 阈值 = 近60日振幅的 Q0.33 × 0.58（限 0.4%~1.5%）；区触发 = T×0.63；T 单过夜：目标 +T×1.4、止损 -T×0.5、最长 5 日。B223 为备选（20日×Q0.48、T×0.59、目标×1.6、止损×0.4）。已落地看板为第三套模型（默认选中）
5. **引擎修复记录**：实现过程中修复了加权分位数闭包的跨调用状态污染（重复调用返回漂移值）与配置缺省字段导致阈值 NaN 两处 bug；固定金额口径下引擎仓位管理按笔记录股数
