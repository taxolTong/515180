# 20261020-t-sizing — 做T手法对比（有限注资额度 + 1年典型区间）

## 目的

在固定信号/阈值/费用的前提下，唯一变量是"每笔做T的数量/金额"，找出最优单笔规模；并检验循环注资额度（3万/5万）的影响。

## 方法

- 命令：`node scripts/t-sizing.mjs`（区间默认自动从 rolling-1y 中位数样本选取，可用第 2/3 参数覆盖起止日期）
- 区间：**2025-08-21 ~ 2026-09-01（250 个交易日 ≈ 1 年）**，取自 rolling-1y 加权年化最接近中位数（8.73%）的样本，代表"最普通"的一年行情，不挑好也不挑差
- 初始本金 1万股 + 1万现金；**循环注资额度 CAP（3万/5万两档）**：现金最低不低于 -CAP、回款自动还贷、任时刻占用不超额
- 变量：固定股数 1万/5000/2000、仓位比例 50/25/10%、固定金额 1万/5000元；除原方案参照外带清仓等待规则
- 收益率 = 期末净资产 / 期初本金 23210 元

## 结果

- **最优：注资5w + 固定1万股/笔（原方案手法），+38.61%**（做T 119 次、胜率 52.9%、T净收益 +1997、费用 1230、最大注资占用 3.82w）
- 注资5w 档：pct仓位50% +36.19%、amount固定1万 +35.03%、固定5000股 +29.32%、固定5000元 +27.36%、pct25% +24.05%；固定2000股 +15.73% 与 pct10% +14.50% 垫底
- 注资3w 档排序相同：固定1万股 +32.36% > pct50% +30.35% > amount1万 +28.57% > … > pct10% +16.38%
- 纯持有参照仅 +3.75%

## 结论

1. **单笔规模越大越好（在额度内）**：1万股/笔 > 5000股 > 2000股；仓位10%/2000股因每笔最低5元佣金 + 高频尾盘平回磨损稳定垫底
2. **额度越大收益越高**（本区间低估区时间长、打满额度抄底所致），但该结论依赖行情——额度是收益放大器而非免费午餐
3. 原方案手法（固定1万股 + 额度约束）在本框架下就是最优，无需改手法；改进方向在额度管理与成本控制
