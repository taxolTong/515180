# 20261020-rolling-1y — 滚动建仓一年回测

## 目的

检验纪律性操作在"任意一天建仓、坚持一年"下的收益分布——为后续所有稳定性实验提供样本框架（建仓起点 + 持有 250 交易日 + 日历年化）。

## 方法

- 命令：`node scripts/rolling.mjs`
- 每个有效交易日建仓（10000股底仓 + 10000现金），坚持纪律持有 250 个交易日，按日历天数年化
- 样本：230 个建仓点（2024-10-28 ~ 2025-09-30；受腾讯接口 640 条日K上限所限）

## 结果

- 近期加权：年化中位数 8.73%，P(年化>15%) = 1.3%，P(年化<10%) = 61.3%
- 等权全样本：年化中位数 7.85%，P(年化>15%) = 0%，P(年化<10%) = 75.2%

## 结论

纪律操作的单年期望年化 ~8%，明显跑赢纯持有，但单年波动大、绝大多数年份不到 10%——为后续"做T手法/规模优化"实验提供基线样本（其中年化最接近中位数的样本被 t-sizing 选为"最普通一年"的测试区间）。
